如果以「一般常見做法的牛奶量」由多到少排序，常見的順序大致是：

1. Latte（拿鐵）— 最多：以大量蒸奶為主，奶味最明顯。  
2. Mocha（摩卡）— 接近拿鐵：與拿鐵相似的牛奶量，但加了巧克力或可可風味，因此口感不同。  
3. Cappuccino（卡布奇諾）— 中等：通常為義式濃縮 + 少量蒸奶 + 厚奶泡（奶量比拿鐵少）。  
4. Macchiato（瑪奇朵）— 很少：通常只是「一點」奶或奶泡點綴在濃縮上。  
5. Americano（美式）— 最少／無：基本上是濃縮加熱水，通常不含牛奶（若加奶則稱為含奶變體）。

備註：各家咖啡店的配方與杯量會有差異（例如拿鐵杯型大小、摩卡加巧克力後奶量調整等），上述為一般常見的相對排序。需要我把每種飲品的典型奶量範圍列成數值嗎？

通常可能含巧克力的咖啡（由高到低可能性）：

1. Mocha（摩卡）— 最常見且典型含巧克力（巧克力醬或可可粉＋義式濃縮＋牛奶）。  
2. Cappuccino（卡布奇諾）— 常見會在頂部撒可可粉或加入一點巧克力調味。  
3. Latte（拿鐵）— 可被做成巧克力拿鐵（加入巧克力醬或可可），但原始拿鐵不一定含巧克力。  
4. Macchiato（瑪奇朵）— 通常不含巧克力，但有些變體會加入巧克力風味或醬料。  
5. Americano（美式）— 基本上不含巧克力（若加則為變體）。

##  想減肥的人要喝甚麼咖啡
✔ 請輸入你的問題： 想減肥的人要喝甚麼咖啡

[呼叫 tool] search_coffee({"query":"低熱量 減肥 黑咖啡 無糖","limit":10})
想減肥的人喝咖啡時，原則是以「低熱量、少糖少奶」為主。建議如下（繁體中文）：

建議飲品（由最適合到次之）
- 黑咖啡／美式（Americano）或濾泡黑咖啡：幾乎零熱量，是最佳選擇。  
- 濃縮咖啡（Espresso）：小杯但低熱量，方便控制整體攝取。  
- 冷萃（Cold brew）無糖：口感順、酸度低，同樣低熱量。  
- 低脂牛奶拿鐵（小杯、無糖）或少奶卡布奇諾：若很難接受完全黑咖啡，可選低脂或減量牛奶、杯量縮小。

應避免或少喝
- 含糖糖漿、摩卡、含奶油或鮮奶油的飲品（熱量高）。  
- 「子彈咖啡」/ 加奶油、椰子油等脂肪飲品（熱量非常高，不利減重）。  
- 大杯加糖拿鐵、焦糖瑪奇朵等甜飲。

實用小技巧
- 點餐時明確說「無糖／不加糖漿／少奶／用脫脂或燕麥奶（注意熱量）」。  
- 用肉桂粉或可可粉少量調味（幾乎不增加熱量），代替糖。  
- 若對咖啡因敏感或晚上睡眠受影響，可選低咖啡因或脫咖啡因（decaf）版本。  
- 運動前30–60分鐘喝一杯黑咖啡可提升表現與代謝，但效果有限，減重仍以總熱量赤字為主。

安全提醒
- 健康成人每日咖啡因建議上限約400 mg（約4杯濃度一般的咖啡）；孕婦、心血管或焦慮症患者應諮詢醫師。  
- 咖啡只是輔助，持續減重仍需控制飲食總熱量與增加活動量。
